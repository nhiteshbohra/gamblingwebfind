#
#  HOW TO ADD A NEW SOURCE:
#  ────────────────────────
#  Each non-comment line follows this format:
#
#    id | Name | URL_or_local_path
#
#  Fields:
#    id   — short unique identifier (letters, numbers, underscores only)
#    Name — human-readable label shown in logs and MongoDB reason field
#    URL  — GitHub /blob/ URL, raw URL, or a local file path (.txt/.csv/.xlsx)
#
#  TIPS:
#    - Lines starting with # are comments and are ignored
#    - Blank lines are ignored
#    - Both GitHub /blob/ URLs and raw.githubusercontent.com URLs work
#    - Local file paths (absolute or relative to project root) also work
#    - All formats auto-detected: Hosts, AdBlock, RPZ, Dnsmasq, Wildcard, plain domain list
#    - Duplicate domains across sources are automatically de-duplicated
#
#  EXAMPLE — Add a custom source:
#    my_list | My Custom Gambling List | https://example.com/my_domains.txt
#    local_list | My Local Import | C:\Users\me\Downloads\gambling_sites.txt
#
